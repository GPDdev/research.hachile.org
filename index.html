02 / COMPUTER VISION独立开发

IASR System：空中态势识别集成系统

以视频感知为入口，将检测、跟踪、态势分析与事件预警整合为统一系统。

IASR System 是一个可扩展的低空态势识别与预警集成系统。系统以视频为输入，进行目标检测与跟踪，计算交通态势指标（流量、占有率、速度）与拥堵指数，同时给出基于视频清晰度的能见度态势估计（雾、霾、烟的代理指标），最终输出统一格式的事件，并根据配置将事件路由给运行、安防、应急、交管等对象。

项目基于 Streamlit 仪表盘开发，通过 YOLO 实现视频目标检测与跟踪，OpenCV 实现静态图片识别。

✦项目获同济大学国豪书院第三届“研学济豪”海报展三等奖。

  • Streamlit
  • YOLO
  • OpenCV
  • 目标跟踪

03 / TIME-SERIES ANALYSIS独立开发

基于时序设计的多模态驾驶室座椅压力分析系统

通过压力分布的时序分析，为座椅优化与人机工程学研究提供数据支持。

本项目是一个专门用于分析驾驶室座椅压力传感器数据的时序数据分析工具。通过采集用户在座椅上的压力分布数据，系统可以分析不同体重组别的压力变化趋势、稳定性指标以及时序特征，为座椅设计优化和人机工程学研究提供数据支持。

项目数据由同济 XAI Lab 提供，我在 2025 年 11 月完成代码编写。项目使用 pandas 进行数据处理和分析，NumPy 进行数值计算和矩阵操作，Matplotlib 实现数据可视化。

  • pandas
  • NumPy
  • Matplotlib

05 / DRIVER MONITORING开发小组成员

AI“安全副驾”：驾驶员分心与疲劳状态智能监测

舱内状态识别与舱外环境感知并行运行，构建轻量化主动安全原型。

本项目采用“舱内监控＋舱外感知”双轨并行的技术路线：舱内基于 MediaPipe 面部关键点，通过眼睛与嘴部纵横比等几何规则逻辑判定驾驶员状态；舱外采用轻量级 YOLOv8n 模型实现车辆检测与单目视觉测距。

系统通过 Python 多进程（生产者－消费者）架构实现双路视频流的实时并发处理与预警。最终目标是构建一个集成化、轻量化且具备科学验证的主动安全解决方案。

  • MediaPipe
  • YOLOv8n
  • 单目测距
  • Python 多进程

07 / EMBODIED INTELLIGENCE开发小组成员

QDepth-VLA：轻量级视觉模型赋能果园采摘

只用普通 RGB 摄像头，将三维几何理解融入视觉－语言－动作模型。

QDepth-VLA 通过先用单目深度模型生成伪深度，再把连续深度用 VQ-VAE 离散成 256 个深度 token，通过一个 Depth Expert 和 Hybrid Attention 把几何信息注入到 VLA 主干的中间表征里，联合优化“动作损失＋深度 token 损失”，并在训练过程中逐步衰减深度监督权重。

本项目提出并落地一套仅依赖普通 RGB 摄像头的低成本采摘引导方案：在推理阶段只输入 RGB 图像，通过 QDepth-VLA 将三维几何理解“内化”到视觉－语言－动作模型中。

项目构建了果园专用数据集，并基于开源 Open-π₀ 嫁接深度专家模块进行指令微调，最终在仿真（Isaac Sim / LIBERO）与桌面机械臂平台完成“识别－定位－采摘”闭环原型验证。

  • VLA
  • VQ-VAE
  • Open-π₀
  • Isaac Sim / LIBERO
08 / AI FOR SCIENCEAI and Energy 在投

基于人工智能的锂金属电池锂枝晶生长分析与预测结合机器学习与多尺度模拟

融合形貌图像、电化学时间序列与材料参数，研究枝晶生长的分析和预测。

本文引入人工智能对枝晶形貌与动力学进行综合分析与预测：基于实验室数据构建包含扫描电镜图像、电化学充放电时间序列及电解质与界面特征参数的多源数据集，利用 CNN 实现枝晶形貌自动识别与分级，并以分形维数、枝晶长度和占比等指标量化。

进一步建立一维卷积结合循环神经网络的时间序列模型，预测极化电压与过电位波动，并对失控生长风险进行预警；最后用回归模型将电解质组成与传输性质映射到枝晶生长速率和形貌特征，用于筛选抑制枝晶的电解质体系。

结果显示，该 AI 框架在形貌识别与电化学响应预测上精度较高，且能给出与物理化学机理一致的特征重要性，为锂金属电池安全设计提供高通量、可解释的新思路。

  • CNN / RNN
  • 多源数据
  • 多尺度模拟
  • 可解释机器学习
